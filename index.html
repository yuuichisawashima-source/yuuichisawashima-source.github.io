Beautiful Future

スキンケア特化 TikTok コンテンツ管理プラットフォーム

サービス概要

Beautiful Future は、スキンケア領域に特化した TikTok コンテンツの企画・制作・投稿・分析を一元管理するプラットフォームです。AI を活用してカルーセル（写真モード）や動画コンテンツを効率的に制作し、TikTok Content Posting API を通じて投稿します。

主な機能

AI コンテンツ生成

スキンケアに関するトレンド分析をもとに、フック・本文・ハッシュタグを AI が自動生成。カルーセル画像も自動レイアウトします。

TikTok 自動投稿

TikTok Content Posting API と連携し、カルーセル（写真モード）および動画をアプリから直接投稿。プライバシー設定も柔軟に管理できます。

パフォーマンス分析

再生数・いいね・保存率・フォロワー増減を自動取得し、投稿ごとのパフォーマンスを可視化。次の施策に活かします。

マルチアカウント管理

複数の TikTok アカウントを一元管理。アカウントごとにペルソナ・テーマ・カラースキームを設定し、統一感のある運用が可能です。

利用の流れ

  1. TikTok アカウント連携 OAuth 2.0 認証でお使いの TikTok アカウントを安全に連携します。投稿権限のみを取得し、パスワードは保存しません。
  2. コンテンツ企画・生成 トレンド分析に基づき、AI がスキンケアに特化したカルーセルや動画コンテンツを自動生成します。
  3. レビュー・編集 生成されたコンテンツを確認・編集。テキスト、画像、ハッシュタグを自由にカスタマイズできます。
  4. TikTok へ投稿 Content Posting API を通じて TikTok に直接投稿。公開範囲（全員公開 / フォロワーのみ / 非公開）を選択できます。
  5. 分析・改善 投稿後のパフォーマンスデータを自動収集し、次のコンテンツ改善に活用します。

TikTok API 連携について

本サービスは TikTok の公式 Content Posting API を使用しています。ユーザーの明示的な許可（OAuth 2.0 認証）を得た上で、以下のスコープのみを利用します：

  • user.info.profile — プロフィール情報の取得
  • user.info.stats — フォロワー数等の統計情報
  • video.list — 投稿一覧・メトリクスの取得
  • video.publish — コンテンツの投稿

プライバシーポリシー

Beautiful Future（以下「本サービス」）は、ユーザーの個人情報の保護を重視しています。

1. 収集する情報

  • TikTok OAuth 認証を通じて取得するアクセストークン・リフレッシュトークン
  • TikTok プロフィール情報（ユーザーID、表示名）
  • 投稿のパフォーマンスデータ（再生数、いいね数、保存数等）

2. 情報の利用目的

  • TikTok へのコンテンツ投稿機能の提供
  • 投稿パフォーマンスの分析・レポート作成
  • サービスの改善・新機能の開発

3. 情報の保管・保護

認証トークンはユーザーのローカル環境に暗号化して保存されます。第三者のサーバーに送信・保管されることはありません。

4. 第三者への提供

ユーザーの個人情報を第三者に販売・貸与・開示することはありません。法令に基づく開示要求がある場合を除きます。

5. データの削除

ユーザーはいつでも TikTok アカウントの連携を解除し、保存されたデータの削除を要求できます。連携解除は TikTok の設定画面からも実行可能です。

6. お問い合わせ

プライバシーに関するお問い合わせは privacy@beautifulfuture10.site までご連絡ください。
